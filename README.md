---

## 📄 Descripción

Maquetado de la página inicial de **Nave** ([navenegocios.ar](https://navenegocios.ar/home)), una plataforma de cobros digitales para negocios.

El trabajo consiste en reproducir los principales componentes visuales del sitio utilizando HTML semántico y CSS puro, con diseño adaptable a distintos tamaños de pantalla.

---

## 🧩 Componentes desarrollados

- **Header** — Navegación con logo, links y botones de acción. Implementado con `position: sticky` para que permanezca visible al hacer scroll.
- **Sección "Vuelo de tu negocio"** — Presentación con título y 3 tarjetas de beneficios con íconos SVG.
- **Sección "Cobrá como querés"** — Presentación de los medios de cobro (QR y Terminal Nave Point) con imágenes reales y layout de 2 columnas.
- **Footer** — Logo y 4 columnas de links organizados semánticamente.

---

## 📱 Responsive Design

El sitio se adapta correctamente a los siguientes tamaños de pantalla:

| Breakpoint | Dispositivo |
|------------|-------------|
| 320px      | Móvil pequeño |
| 768px      | Tablet |
| 1024px+    | Desktop |

Se utilizaron **media queries** para adaptar el layout, tipografía y espaciado en cada resolución.

---

## 🛠️ Tecnologías utilizadas

- HTML5 semántico (`header`, `nav`, `section`, `footer`)
- CSS3 (Flexbox, media queries, transitions)
- Git y GitHub Pages para el deploy
